\# EdTech Core Engine (Homeschooling \& Co-op Architecture)



An open-source, modular backend engine designed to manage localized homeschooling frameworks, curriculum credit mapping, and community co-op scheduling. 



\*Note on Repository History: Active development on this architecture began locally in late 2026 as an offline workspace. The codebase is currently being migrated to this dedicated personal GitHub repository to manage upcoming modular releases, CI/CD pipelines, and AI-assisted feature expansion.\*



\## Core Modules

1\. \*\*Curriculum Engine:\*\* Maps localized state-board requirements (NIOS, IGCSE) against custom student milestones.

2\. \*\*Co-op Resource Scheduler:\*\* Real-time event and slot management for local parent communities.

3\. \*\*RBAC API:\*\* Granular role-based access control for Administrators, Parents, and Student views.



\## Tech Stack

\* Node.js / Express

\* TypeScript

\* Prisma ORM (PostgreSQL)

\* Jest (Automated Test Suites)
