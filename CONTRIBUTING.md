\# Contributing to EdTech Core Engine



\## Local Development Setup

1\. Clone the repository.

2\. Run `npm install` to install dependencies.

3\. Start the local database using `docker-compose up -d`.

4\. Copy `.env.example` to `.env`.

5\. Run `npx prisma db push` to sync the schema.

6\. Run `npm run dev` to start the local server.



Please ensure all tests pass (`npm test`) before opening a Pull Request.
